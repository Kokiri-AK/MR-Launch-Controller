# MR-Launch-Controller
Model Rocket Launch Controller Schematic

Original Schematic: Ryan Wilkus

Forked by Jonathan M

Circuit is originally based on a great paper from 2009 by J.R. Brohm discussing model rocket igniter continuity testing [Paper](https://www.rocketshoppe.com/info/Igniter_Continuity_Tests.pdf). 

The paper proposed using a transistor circuit to decrease the continuity check current of the igniter. This circuit is an expanded realization of that suggestion.
